# 🎵 Laboratorio de Audio y Video en HTML5

Este repositorio contiene una implementación básica en HTML5 que demuestra el uso e integración de contenido multimedia nativo utilizando las etiquetas `<video>` y `<audio>`.

El laboratorio incluye reproducción de video con controles integrados y reproducción de audio en bucle continuo (*loop*).

---

## 🚀 Características

* **Reproducción de Video Nativa:** Integración de la etiqueta `<video>` con el atributo `controls` para pausar, reproducir y ajustar volumen de un archivo MP4.
* **Reproducción de Audio Nativa:** Uso de la etiqueta `<audio>` con reproducción en bucle (*loop*) habilitada.
* **Sin Dependencias:** Implementación utilizando únicamente HTML5 estándar, compatible con todos los navegadores modernos.

---

## 🛠️ Tecnologías Utilizadas

* **HTML5:** Etiquetas nativas `<video>`, `<audio>` y `<source>`.
